# Картинки серии дней

По одной картинке на порог серии. Она заполняет карточку на главном
экране, поверх неё слева — счётчик, заголовок и подпись.

| Файл | Когда показывается |
| --- | --- |
| `seed.jpg` | 0 дней |
| `spark.jpg` | 1 день |
| `rolling.jpg` | 3 дня |
| `week.jpg` | 7 дней |
| `fortnight.jpg` | 14 дней |
| `month.jpg` | 30 дней |
| `iron.jpg` | 60 дней |
| `legend.jpg` | 100 дней |
| `beyond.jpg` | больше 100 дней |

## Правила

- **Имя файла менять нельзя** — по нему всё и связывается. Пороги заданы
  в `src/data/streakTiers.ts`, там же цвет и иконка каждого порога.
- Размер — **1000x490** (соотношение 2.05:1).
- Текст лежит в левых двух третях, поверх картинки затемнение слева
  направо. Сюжет держите справа.
- Сейчас это **заглушки** — градиент с лепестками в цвет порога.
- Формат — **JPG**. Если нужен PNG, поменяйте расширение в
  `src/data/streakImages.ts`.
