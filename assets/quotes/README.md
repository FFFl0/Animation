# Озвучка цитат

Здесь лежит по одному звуковому файлу на персонажа — та же реплика, что
показана текстом в вопросе «Кто это сказал?». Текст никуда не девается:
звук идёт **в дополнение**, чтобы в шумном месте или с выключенным
звуком вопрос читался как раньше.

Сейчас это **заглушки** — короткий двухнотный сигнал. Заменяйте их на
настоящие реплики по одной, в коде ничего трогать не нужно.

## Правила

- **Имя файла менять нельзя** — по нему всё и связывается. Файл должен
  называться `<id персонажа>.mp3`, где id берётся из
  `src/data/characters.ts`.
- Формат — **MP3**. Играет везде без оговорок; 64–96 кбит/с моно более
  чем достаточно для реплики.
- Длина — по длине самой реплики, обычно 2–5 секунд. Реплика
  проигрывается один раз при появлении вопроса, повтор — по кнопке.
- Пока реплика звучит, фоновая музыка приложения приглушается и
  возвращается сама.
- Если файла для персонажа нет, вопрос не сломается — просто не будет
  кнопки «Послушать цитату».

## Если персонаж добавится

1. Положить `<новый-id>.mp3` сюда.
2. Дописать строку в `src/data/quoteAudio.ts` — Metro требует строковых
   литералов в `require()`, автоматически это не подтянется.
