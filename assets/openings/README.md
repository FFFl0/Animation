# Ролики для категории «Опенинги и эндинги»

Здесь лежит по одному ролику на аниме. Приложение проигрывает его и
спрашивает, из какого это аниме.

Сейчас это **заглушки** — цветная карточка с идентификатором аниме и
надписью OPENING PLACEHOLDER. Заменяйте их на настоящие заставки по
одной, ничего в коде трогать не нужно.

## Правила

- **Имя файла менять нельзя** — по нему всё и связывается. Файл должен
  называться `<id аниме>.mp4`, где id берётся из `src/data/animeSeries.ts`.
- Формат — **H.264 + AAC в `.mp4`**. Это единственная связка, которую
  без оговорок играют и Android, и iOS.
- Ролик зациклен, так что 8–15 секунд достаточно; длинный файл только
  раздувает сборку.
- Разумный размер кадра — 640x360 или 854x480. Ролик показывается в
  рамке шириной с экран телефона, больше смысла нет.
- Звук у ролика свой, поэтому на этой категории фоновая музыка
  приложения выключается автоматически.

## Если аниме добавится

1. Положить `<новый-id>.mp4` сюда.
2. Дописать строку в `src/data/openingVideos.ts` — Metro требует
   строковых литералов в `require()`, автоматически это не подтянется.

Если для аниме ролика нет, вопрос про него не сломается: вместо плеера
покажется надпись «Ролик для этого аниме ещё не добавлен».
