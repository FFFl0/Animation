# Картинки экрана статистики

## `header.jpg`

Шапка экрана: на ней белым лежит заголовок «Статистика» и подпись под ним.

- Размер — **1200x560** (соотношение 2.15:1).
- Текст идёт по левому нижнему краю, поверх картинки затемнение слева
  направо. Сюжет держите справа и сверху.

## `quote.jpg`

Полоса с цитатой в самом низу экрана.

- Размер — **1200x420** (соотношение 2.85:1).
- Текст лежит по центру, поверх — затемнение сверху и снизу.

## Общее

- Сейчас это **заглушки** — градиент с лепестками. Заменяйте на свои:
  имя файла менять нельзя, в коде трогать ничего не нужно.
- Формат — **JPG**. Если нужен PNG, поменяйте расширение в
  `src/data/statsImages.ts`.
- Картинка обрезается по центру под пропорции блока.

Картинки в строках категорий отдельно класть не нужно: там переиспользуются
фоны из `assets/categories`.
