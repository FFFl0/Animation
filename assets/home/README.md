# Фоны главного экрана

## `fan-battle.jpg`

Фон карточки «Битва фанатов» — широкая полоса под заголовком категорий.

- Размер — **1200x462** (соотношение 2.6:1). Карточка тянется по ширине
  экрана, так что на разных телефонах пропорция чуть плавает: не
  прижимайте сюжет к левому и правому краям.
- Слева лежит белый текст (название и подпись), поверх картинки там
  затемнение. Смысловую часть рисунка держите по центру и справа.

## `tournament.jpg`

Фон карточки «Турнир», под «Битвой фанатов».

- Размер — **1200x343** (соотношение 3.5:1).
- Как и у битвы: текст слева, поверх него затемнение, сюжет держите
  по центру и справа.

## `modes/<id режима>.jpg`

По одной картинке на игровой режим. Карточки прокручиваются вбок под
заголовком «Игровые режимы».

- Размер — **570x336** (соотношение 1.7:1).
- **Имя файла менять нельзя** — по нему всё и связывается. id берутся из
  `src/data/modes.ts`: `quick`, `survivor`, `perfect10`, `silhouette`,
  `eyes`, `whoSaidIt`, `whichAnime`, `mixed`, `daily`.
- Текст лежит в нижней части карточки, поверх него затемнение. Сюжет
  лучше держать в верхней половине.

## Общее

- Формат — **JPG**. Прозрачность не нужна, а PNG весил бы в разы больше.
  Если всё-таки нужен PNG, поменяйте расширение в `src/data/modeImages.ts`.
- Картинка обрезается по центру под пропорции карточки, так что мелкие
  детали по краям могут не попасть в кадр.
- Держите файлы небольшими (десятки килобайт): все они попадают в сборку.
