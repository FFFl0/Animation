# Фоны категорий квиза

По одной картинке на категорию. Она заполняет всю плитку на главном
экране, поверх неё — название, подпись и кнопка «Начать».

Заменять их можно в любой момент — просто положите свою картинку
под тем же именем, в коде ничего трогать не нужно.

## Правила

- **Имя файла менять нельзя** — по нему всё и связывается. Файл должен
  называться `<id категории>.jpg`, где id берётся из
  `src/data/categories.ts`: `anime`, `characters`, `openings`, `quotes`,
  `battles`, `world`, `hard`, `mixed`.
- Формат — **JPG** (можно и PNG, но тогда поменяйте расширение в
  `src/data/categoryImages.ts`).
- Размер — примерно **560x500**, этого хватает и на экранах с высокой
  плотностью пикселей. Картинка обрезается по центру под пропорции
  плитки, так что главное не прижимайте сюжет к краям.
- Поверх картинки лежит лёгкое затемнение, но текст всё равно белый:
  слишком светлая картинка будет читаться хуже. Если берёте светлый
  кадр — лучше затемнить его заранее.
- Держите файлы небольшими (десятки килобайт): все восемь попадают
  в сборку целиком.
