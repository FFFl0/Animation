# Anime Quiz

Мобильная викторина про аниме-персонажей на Expo (React Native + TypeScript):
175 персонажей (девушки и парни) из ~90 аниме, 5 режимов, локальные аккаунты
с профилем и лидерборд.

## Режимы викторины

- **Угадай по фото** — по стилизованному SVG-портрету персонажа выбрать имя из 4 вариантов
- **Угадай по глазам** — то же самое, но по крупному кадру одних лишь глаз
- **Угадай по описанию** — по короткой текстовой подсказке
- **Из какого аниме?** — по портрету персонажа назвать сериал (варианты — разные тайтлы)
- **Вопросы про персонажа** — конкретный факт про названного персонажа (например, «Кто подарил Микасе красный шарф?»)

Каждый раунд — 50 вопросов, персонажи и варианты ответа выбираются случайно.

Никаких сторонних изображений: портреты — это оригинальные векторные
(SVG) аватары, собранные по параметрам персонажа (цвет/причёска волос,
цвет глаз, значок-акцент), а не скопированный чужой арт.

## Аккаунты и профиль

Регистрация/вход — локальные, аккаунт хранится только на устройстве
(без бэкенда): пароль хешируется (SHA-256 + соль) через `expo-crypto`,
в открытом виде не хранится. В профиле:

- Свой настраиваемый SVG-аватар (причёска, цвета, значок)
- Любимый персонаж
- Статистика по каждому из 5 режимов (лучший результат, сыграно игр, точность)

## Лидерборд

Ранжирует все аккаунты, зарегистрированные на этом устройстве (полезно,
если несколько человек играют с одного телефона): общий счёт (сумма
лучших результатов по всем режимам) и отдельная вкладка на каждый режим.

## Запуск

```bash
npm install
npm start        # откроет Expo DevTools / Metro
npm run web       # запустить в браузере
npm run ios       # запустить в iOS-симуляторе (нужен macOS)
npm run android   # запустить в Android-эмуляторе
```

## Структура

```
App.tsx                         # авторизация + переключение экранов
src/auth/                       # локальные аккаунты (регистрация/вход/профиль)
src/data/characters.ts          # база персонажей: имя, аниме, описание, вопрос/ответ, аватар
src/quiz/generateQuiz.ts        # генерация вопросов под каждый из 5 режимов
src/screens/HomeScreen.tsx      # выбор режима викторины
src/screens/QuizScreen.tsx
src/screens/ResultScreen.tsx
src/screens/ProfileScreen.tsx
src/screens/LeaderboardScreen.tsx
src/components/AnimeAvatar.tsx  # SVG-портрет персонажа (react-native-svg)
src/components/EyesPreview.tsx  # крупный кадр глаз для режима «по глазам»
src/theme.ts                    # цветовая палитра приложения
```

## Как добавить персонажа

Допишите объект в `src/data/characters.ts`:

```ts
{
  id: 'unique-id', name: 'Имя', nameEn: 'Name', series: 'Аниме',
  description: 'Короткая подсказка про персонажа',
  question: 'Вопрос про факт из сюжета', answer: 'Правильный ответ',
  distractors: ['Неверный 1', 'Неверный 2', 'Неверный 3'],
  avatar: { hairColor: '#HEX', hairStyle: 'long', eyeColor: '#HEX', accent: '#HEX', badge: '🎀' },
}
```

`hairStyle` — один из: `long`, `twin`, `bob`, `wavy`, `odango`, `animalEars`, `horns`, `wild`.
